# Reaction-pathway analysis

This directory is reserved for the catalytic application stage of the project.

## Planned objective

Use the trained NequIP potential to evaluate structures along the formate decomposition pathway on Cu and compare the resulting MLIP energy profile with the corresponding DFT reference profile.

## Planned workflow

1. Identify or extract structures belonging to the reaction pathway.
2. Order the structures along a physically meaningful reaction coordinate.
3. Evaluate every pathway structure with the trained MLIP.
4. Reference DFT and MLIP energies to the same initial state.
5. Compare reaction energies and barrier-region behavior.
6. Plot DFT and MLIP reaction-energy profiles.
7. Examine structures where the MLIP error is largest.
8. Assess whether the model is sufficiently accurate for pathway interpolation and later ML-driven dynamics.
